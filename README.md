# 嘎嘎小狗总结

SillyTavern 1.18.0+ 的剧情记忆扩展。它把过长聊天压缩为有文笔的前情、结构化状态和场景记忆，在保存并校验成功后自动将已覆盖的旧消息退出模型上下文；原消息不会被删除，可以恢复。

## 当前版本

- 使用 SillyTavern 当前连接和模型，不需要额外 API Key。
- 总结优先使用 SillyTavern 的 Quiet 后台生成通道，与酒馆正常对话共用连接、预设和请求链；仅在 Quiet 不可用时才回退 Raw。
- 事实提取与文学前情分离；文学版会参考当前预设和正文样本。
- 保存场景卡、事实、当前状态、关系、未结事项和检查点。
- 通过消息哈希检测编辑、删除和 Swipe，使受影响的检查点失效。
- 自动隐藏由插件处理的旧消息，并支持一键恢复。
- 通过扩展提示词把记忆发送到正常回复请求中；注入内容可预览。
- 关键词召回已内置，向量召回暂未作为首版依赖。
- 提供安全注入（只发事实）和平衡注入（事实与文学前情）两种模式。

## 安装

把整个 `gaga-dog-summary` 目录放到：

```text
SillyTavern/data/<你的用户>/extensions/gaga-dog-summary/
```

刷新页面，在扩展设置中点击“打开嘎嘎小狗总结”，或使用右下角的悬浮按钮。

## 使用建议

1. 第一次使用先点击“立即总结”，确认前情和注入预览。
2. 默认保留最近 10 条消息作为原始正文和文风锚点。
3. 默认在成功保存后自动隐藏已覆盖的旧正文。
4. 发现编辑或 Swipe 后出现橙色失效提示时，等待自动重建或点击“恢复并重建”。
5. 如果担心总结文字影响主模型文风，可选择“安全：只发事实”；如果希望模型获得更连贯的叙事前情，可选择“平衡：事实与前情”。

## API 兼容说明

v0.1.2 起不再把 Raw 结构化请求作为默认总结通道。若酒馆正常聊天可用，但旧版插件总结时出现 502，请更新后刷新酒馆页面再试。插件会先通过酒馆的 Quiet 后台生成完成事实提取与文学前情；只有当前版本的 SillyTavern 不提供 Quiet 接口或返回空内容时，才尝试 Raw 兼容通道。

## 数据安全

- 总结请求会把待总结正文发送给当前配置的模型服务。
- 正常聊天时，已自动隐藏的旧正文不会再次发送；发送的是压缩后的记忆。
- 插件不删除聊天消息，不上传到额外服务器。
- 用户原本手动隐藏的消息不会被插件自动恢复。
