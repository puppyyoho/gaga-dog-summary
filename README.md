# 嘎嘎小狗总结

SillyTavern 1.18.0+ 的剧情记忆扩展。它把过长聊天压缩为有文笔的前情、结构化状态和场景记忆，在保存并校验成功后自动将已覆盖的旧消息退出模型上下文；原消息不会被删除，可以恢复。

## 当前版本

- 使用 SillyTavern 当前连接和模型，不需要额外 API Key。
- 总结优先复用 SillyTavern 当前主聊天的 Chat Completion / Text Completion 服务与 `normal` 参数构造链，直接接收 SSE 流；只有当前 API 类型未暴露扩展流式服务时才回退 Quiet/Raw。
- 事实提取和文学前情均支持实时流式显示、立即中断和继续；中断任务保存在当前聊天元数据中，完成前不会隐藏原消息。
- 事实提取与文学前情分离；文学版会参考当前预设和正文样本。
- 保存场景卡、事实、当前状态、关系、未结事项和检查点。
- 通过消息哈希检测编辑、删除和 Swipe，使受影响的检查点失效。
- 自动隐藏由插件处理的旧消息，并支持一键恢复。
- 通过扩展提示词把记忆发送到正常回复请求中；注入内容可预览。
- 关键词召回已内置，向量召回暂未作为首版依赖。
- 提供安全注入（只发事实）和平衡注入（事实与文学前情）两种模式。

## 安装

把整个 `gaga-dog-summary` 目录放到：

```text
SillyTavern/data/<你的用户>/extensions/gaga-dog-summary/
```

刷新页面，在扩展设置中点击“打开嘎嘎小狗总结”，或使用右下角的悬浮按钮。

## 使用建议

1. 第一次使用先点击“立即总结”，确认前情和注入预览。
2. 默认保留最近 10 条消息作为原始正文和文风锚点。
3. 默认在成功保存后自动隐藏已覆盖的旧正文。
4. 发现编辑或 Swipe 后出现橙色失效提示时，等待自动重建或点击“恢复并重建”。
5. 如果担心总结文字影响主模型文风，可选择“安全：只发事实”；如果希望模型获得更连贯的叙事前情，可选择“平衡：事实与前情”。

## 流式生成、停止与继续

v0.1.3 起采用与“嘎嘎世界锻造”和“嘎嘎人设生成器”相同的酒馆接口适配：Chat Completion 使用主聊天的 `normal` 参数构造器，Text Completion 使用当前预设生成 payload，并由酒馆对应服务发送流式请求。插件不再把 `generateRaw()` 或 Quiet 作为首选通道。

生成进度框会实时显示模型已返回的内容。点击“中断”后，插件会终止当前请求，保留正在处理的消息范围、已完成的事实阶段和当前阶段输出；点击“继续”会从事实提取或文学前情阶段恢复。只有事实与前情全部生成、解析并保存成功后，旧正文才会自动退出上下文。

如果上游代理缓冲 SSE，生成仍可完成，但可能只在最后一次性出现完整内容。面板会显示有效分片数量，便于区分真正流式和上游缓冲。

## API 兼容说明

若直接流式通道不受当前 API 类型支持，插件会依次尝试 Quiet 和 Raw 兼容通道，并在错误中显示实际 API 来源及详细响应。酒馆正常聊天可用但插件仍出现 502 时，请保留完整错误文本，以便判断是 Chat Completion 参数构造、反向代理还是模型端拒绝。

设置页入口使用 SillyTavern 标准扩展抽屉，并针对手机窄侧栏强制横向排版；按钮空间不足时会省略文字，不会再逐字竖排。

## 数据安全

- 总结请求会把待总结正文发送给当前配置的模型服务。
- 正常聊天时，已自动隐藏的旧正文不会再次发送；发送的是压缩后的记忆。
- 插件不删除聊天消息，不上传到额外服务器。
- 用户原本手动隐藏的消息不会被插件自动恢复。
