# 嘎嘎小狗工坊

SillyTavern 1.18.0+ 的剧情记忆扩展。它把过长聊天压缩为有文笔的前情、结构化状态和场景记忆，在保存并校验成功后自动将已覆盖的旧消息退出模型上下文；原消息不会被删除，可以恢复。

## 当前版本

v0.5.0 将“完整剧情梳理”和“分层滚动记忆”拆成两个独立入口、独立页面和独立操作区，不再使用模式下拉框。取消旧的 60000 Token 自动总结触发；近期消息只按楼层完整保留，默认 5 楼且不受 Token 限制。滚动记忆只有点击“启动自动记录”后才会运行，可以随时停止自动记录或中断当前梳理；任一自动任务报错后会立即暂停，不会无休止重试：

- **完整剧情梳理**：从全部旧正文提取事实、状态、场景和未结事项，再生成可选的小说版、结构化版或混合版。文学版先写忠实草稿，再参考原正文的文风锚点润色；结构化事实始终是不可越过的边界。
- **分层滚动记忆**：每轮结束后生成增量剧情胶囊，达到阈值后自动梳理为长期记忆，也可以手动立即梳理、停止自动记录、停止当前梳理及恢复最近一次归档。
- **情节导演**：按内置风格或用户自定义要求生成长线主线、当前分支和伏笔；可选择慢热、均衡、快速、动态或自定义推进，并分别开关主线、分支、伏笔、新角色、支线和自动节拍跟踪。规划是“未来建议”，不会冒充已发生记忆。
- **故事日历（情节导演内）**：内置公历节日、2025–2030 年常用农历节日和 24 节气提醒；用户可以添加纪念日、生日、剧情期限或生理期等一次性、年度和周期事件。故事日期优先从手动指定、最近正文、记忆和角色卡背景读取，并在界面显示来源与置信度；没有明确日期时不会擅自套用现实日期，需用户手动指定后才会触发日期提醒。节气使用常用近似日期，具体年份可能前后浮动一天，未覆盖年份的农历节日可手动添加。
- **代写回复**：根据当前正文生成五个不同意图的用户回复，可选第一/第三人称、仅对白/简单动作/完整行动描写；候选可以复制或放入酒馆编辑栏，但不会自动发送。

记忆、导演和代写可以分别绑定当前酒馆连接、酒馆 Connection Manager 配置或独立 OpenAI 兼容 URL/API Key/模型，因此可以让总结、导演和代写使用不同模型。打开工作台后先进入功能首页，完整梳理、滚动记忆、导演和代写均有各自页面。模型连接另有独立页面。页面视图使用独立滚动区域，切换时会回到新页面顶部。

手动完整梳理仍支持上下文自适应：它会锁定“保留近期消息”之前的全部旧正文，能一次装入当前上下文就整段处理，装不下才自动拆批并连续完成。分层模式的胶囊只记录本轮新增事件、情绪与关系变化、认知边界和未结事项，不重复旧状态；情感线直接融入总结，不额外生成重复的情感报告。只有中断或失败才需要点击“继续”。

## 安装

把整个 `gaga-dog-summary` 目录放到：

```text
SillyTavern/data/<你的用户>/extensions/gaga-dog-summary/
```

刷新页面，在扩展设置中点击“打开嘎嘎小狗工坊”，或使用右下角的悬浮按钮。桌面端可以拖动标题栏移动总结窗口；手机端保持全屏滚动。

## 使用建议

1. 已有长聊天第一次使用分层滚动记忆时，先进入“完整剧情梳理”建立基础记忆；新对话可以直接启动逐轮胶囊。
2. 默认完整保留最近 5 条消息。完整剧情梳理会处理此前全部旧正文；滚动记忆启动后会自动记录新完成的每轮对话，并按“胶囊整理阈值 Token”归档较早胶囊。
3. 默认在成功保存后自动调用酒馆 `/hide` 隐藏已覆盖的旧正文；“恢复隐藏”会调用 `/unhide`，不会删除消息。
4. 发现编辑或 Swipe 后出现橙色失效提示时，等待自动重建或点击“恢复并重建”。
5. 在“完整剧情梳理”或“分层滚动记忆”页面选择要注入正文模型的版本：小说版适合保持连续文气，结构化版适合强调可检索事实，混合版同时保留叙事和必要记忆锚点。实际请求永远只注入当前选中的一个成品，避免三份总结重复发送。
6. 滚动记忆页的“停止自动记录”会关闭后续逐轮任务并中断正在运行的滚动任务；已保存胶囊不会删除。API、格式或网络错误也会自动关闭运行开关，修好配置后需手动点击“启动自动记录”。
7. 在“情节导演 → 故事日历”里点击“从角色卡与正文同步日期”可刷新日期依据；打开“临近时给导演推进建议”后，节日或自定义事件会作为当前回合的可选背景提醒。它不会自动把未来事件写成已发生事实，也不会绕过正文因果强行推进。
8. 导演生成途中可以点击“停止”；停止或失败后点击“续写”会带着保留的部分草稿继续请求，“重新开始”会清掉本次未保存草稿后重新生成，不会删除已经锁定的主线。
9. 导演页的“清空全部”会在二次确认后删除导演主线、分支、伏笔、推进记录、日历事件和未完成草稿；不会删除三个模块的模型连接配置。
10. 若酒馆某版本没有发出生成结束事件，插件只会在确实检测到酒馆仍显示停止控件时拦截导演请求，避免生成已经结束却一直提示“任务进行中”。

一次总结只有同时满足以下三项才算成功：状态栏显示已保存检查点，检查点数量至少为 1，并且当前所选总结成品出现内容。“生成进度 / 原始返回”会依次显示事实结构、前情草稿和文学润色的当前阶段；最后停留在润色稿时，它可能与已保存的成品相同，但原始返回本身仍不代表已经保存。

## 流式生成、停止与继续

当前版本沿用与“嘎嘎世界锻造”和“嘎嘎人设生成器”相同的酒馆接口适配：Chat Completion 使用主聊天的 `normal` 参数构造器，Text Completion 使用当前预设生成 payload，并由酒馆对应服务发送流式请求；只有没有可用的实时服务时才回退 `generateRaw()` 或 Quiet。

生成进度框会实时显示模型已返回的内容。手动总结会读取酒馆当前上下文容量并计算完整提示词 Token：能装下时使用一个事实批次，超出容量时才在后台自适应拆分，用户始终只需点击一次“立即完整梳理”。点击“中断”后，插件会终止当前请求，保留完整目标范围、当前批次、已完成阶段和当前输出；点击“继续”会先恢复中断阶段，再自动完成剩余批次。只有批次完成生成、解析并保存成功后，对应旧正文才会退出上下文。

启用正式文学润色后，每批总结会产生三次后台模型请求：事实提取、前情草稿、文学润色。第三次请求只负责改善语言与结构，结构化事实是不可改变的边界。

如果上游代理缓冲 SSE，生成仍可完成，但可能只在最后一次性出现完整内容。面板会显示有效分片数量，便于区分真正流式和上游缓冲。

## API 与事件说明

默认连接复用酒馆当前 Chat Completion / Text Completion 服务和 `normal` 参数构造链，并保留 Quiet/Raw 兼容回退。独立连接使用浏览器 `fetch` 调用 OpenAI 兼容的 `/chat/completions` 和 `/models`；服务必须允许浏览器跨域访问，否则应改用酒馆自身连接或反向代理。API Key 只保存在当前酒馆扩展设置中，不写入聊天正文、记忆注入或候选回复。

导演执行卡会在每次正常生成前刷新，并通过独立扩展提示词注入；这使用 SillyTavern 的 `GENERATION_AFTER_COMMANDS` 生命周期，因此 slash command 处理完成后、正式 prompt 组装前即可准备当前一轮的导演约束。详细事件和提示词位置以 [SillyTavern 官方事件定义](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/events.js)、[主脚本](https://github.com/SillyTavern/SillyTavern/blob/release/public/script.js) 和 [Prompt Manager 文档](https://docs.sillytavern.app/usage/prompts/prompt-manager/) 为准。

设置页入口使用 SillyTavern 标准扩展抽屉，并针对手机窄侧栏强制横向排版；按钮空间不足时会省略文字，不会再逐字竖排。

## 消息范围与酒馆索引

酒馆消息索引从 `0` 开始，范围两端都包含。插件内部保存的“消息 `0–89`”会对应酒馆的 `/hide 0-89`，不是按人类口语楼层重新换算。设置“保留近期消息 5”时，最后 5 条会完整保留，不受 Token 数量影响；手动梳理只处理此前旧正文，分层模式则在旧楼层已有可靠胶囊后才允许隐藏。

## 数据安全

- 总结请求会把待总结正文发送给当前配置的模型服务。
- 正常聊天时，已自动隐藏的旧正文不会再次发送；发送的是压缩后的记忆。
- 插件不删除聊天消息，不上传到额外服务器。
- 用户原本手动隐藏的消息不会被插件自动恢复。
